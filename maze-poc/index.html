DinoRPG — Maze POC

Dungeon generated → encoded → decoded with the ported DungeonCodec, rendered with Pixi.js using the original DinoRPG dungeon tileset (gfx/dungeon). Each level gets a different skin. The dinoz uses @eternaltwin/dinorpg_animations and walks from the green ring (start) to the purple ring (exit).
